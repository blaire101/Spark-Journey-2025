🎤Key Interview Q&A & 60-second TalkINTERVIEW FOCUS›03

60-second project explanation

•This is a downstream reservation analytics pipeline on AWS.
→Upstream publishes a data-ready event after DWD and DIM are ready.
✓EventBridge starts the Step Functions state machine.
◆Step Functions runs the DM Glue job first.
▸After DM succeeds, two ADS Glue jobs run in parallel.
○S3 stores data, the Glue Data Catalog stores metadata, IAM controls permissions, and CloudFormation provisions the resources.
What is CloudFormation?CORE
•CloudFormation is AWS Infrastructure as Code.
→I declare AWS resources in a template and deploy them together as a stack.
Does CloudFormation run the ETL?TRAP
•No.
→CloudFormation provisions the Glue Job and supporting resources.
✓Glue executes the transformation, while SQL contains the business logic.
Why Step Functions instead of Lambda for orchestration?CORE
•Step Functions makes sequence, synchronous waiting, parallel branches, retry and failure paths explicit.
→Lambda is better for custom code.
Why are the two ADS jobs parallel?CORE
•Both depend on DM, but they do not depend on each other.
→Once DM succeeds, parallel execution reduces end-to-end latency.
Why separate IAM roles?CORE

EventBridge, Step Functions and Glue have different responsibilities, so separate roles let me apply least privilege to each service.

🛠️6. Extra CloudFormation knowledgeGOOD FOLLOW-UP TOPICS›06
Stack

Deployed template instance

Dev, test and prod can deploy the same template with different parameters.

Change Set

Preview before update

Useful for reviewing which resources will be added, modified or replaced.

Rollback

Failure protection

If a stack operation fails, CloudFormation can roll back changes instead of leaving a half-created environment.

Drift Detection

Detect console changes

Checks whether actual resources differ from the template-controlled configuration.

DependsOn

Explicit dependency when required

CloudFormation usually infers dependencies from references. Use `DependsOn` only when the relationship is not otherwise visible.

DeletionPolicy

Protect stateful resources

For important data stores, consider retain/snapshot behavior rather than deleting everything with a stack.

Nested / Reusable Modules

Reduce giant templates

Large organizations often split or wrap infrastructure into reusable modules instead of making every data engineer edit one monolithic YAML.

Secrets

Do not hard-code credentials

Use Secrets Manager / Parameter Store references and IAM rather than embedding passwords in templates.

🎤Terraform Interview Q&A — only the essentialsTERRAFORM QUICK START›03

Eight questions to remember

What is Terraform?CORE
→Terraform is a declarative Infrastructure as Code tool. It uses providers to create and manage infrastructure from HCL configuration.
What does terraform init do?CORE
→It initializes the working directory and downloads the required providers and backend configuration.
What is the difference between plan and apply?CORE
→plan previews the proposed infrastructure changes. apply executes the reviewed changes.
What is Terraform state?CORE
→State maps Terraform configuration to the real resources it manages. It is critical for planning future changes.
What is the Terraform equivalent of !GetAtt Role.Arn?CORE
→You reference the resource attribute directly, for example aws_iam_role.glue_execution.arn.
Does Terraform run the Glue ETL job?CORE
→No. Terraform provisions the Glue Job. Step Functions or another runtime trigger starts the job.
How would Terraform change this demo?CORE
→It would replace CloudFormation as the IaC layer. EventBridge, Step Functions, Glue, IAM and S3 would keep the same runtime responsibilities.
CloudFormation or Terraform — which would you choose?CORE
→For an AWS-only team, CloudFormation is a strong native choice. Terraform is attractive when the organization wants one IaC workflow across multiple services, clouds or platforms.

Five-line memory

1HCL describes the desired infrastructure.
2init prepares providers and backend.
3plan previews changes.
4apply deploys changes.
5state tracks managed resources.
