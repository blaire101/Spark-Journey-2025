DM = reusable business layer

DWD
Detailed facts. Reservation events and paid orders are detailed, cleaned business records.
DIM
Descriptive context. Campaign dimension adds attributes used for analysis and segmentation.

ADS
Consumption outputs. Campaign ADS aggregates metrics; CRM ADS keeps user-level targets.
Interview reason for DMDo not let every ADS repeat the same join and conversion definition. Centralizing shared business logic improves consistency, reuse and maintainability.

This project is a downstream reservation analytics pipeline built on AWS.

中文：这个项目是 AWS 上的下游预约分析管道。

The upstream platform owns DWD and DIM, and it publishes a data-ready event when those datasets are complete.

中文：上游平台负责 DWD / DIM，并在数据就绪时发布事件。

EventBridge matches that event and starts a Step Functions state machine.

中文：EventBridge 匹配事件并启动 Step Functions。

Step Functions runs the DM Glue job first and waits for it to complete, because both ADS datasets depend on the DM output.

中文：先跑 DM 并等待完成，因为两个 ADS 都依赖它。

After DM succeeds, the campaign ADS and CRM ADS jobs run in parallel because they are independent downstream consumers.

中文：DM 成功后两个 ADS 独立，因此并行。

CloudFormation provisions the Glue resources, IAM roles, state machine and EventBridge rule so the environment is repeatable and auditable.

中文：CloudFormation 用代码统一创建 Glue、IAM、状态机和 EventBridge。

📄1. Template StructureBEGINNER FOUNDATION›01
Parameters

Inputs to the template

Examples in this demo: project name, S3 buckets, upstream database names and table names.

Resources

The AWS objects to create

IAM roles, Glue databases/tables/jobs, Step Functions state machine and EventBridge rule.

Important values after deployment

Pseudo Parameters

`AWS::AccountId`, `AWS::Region`, `AWS::Partition` help avoid hard-coding environment-specific values.

🧩4. Map CloudFormation to the DM use caseWHAT EACH RESOURCE DOES›04

AWS::IAM::RoleCreates execution identities for Glue, Step Functions and EventBridge.Provisioning; roles are then used at runtime.

🛠️6. Extra CloudFormation knowledgeGOOD FOLLOW-UP TOPICS›06
Stack

Deployed template instance

Dev, test and prod can deploy the same template with different parameters.

Change Set

Preview before update

Useful for reviewing which resources will be added, modified or replaced.

Rollback

Failure protection

If a stack operation fails, CloudFormation can roll back changes instead of leaving a half-created environment.

Drift Detection

Detect console changes

Checks whether actual resources differ from the template-controlled configuration.

DependsOn

Explicit dependency when required

CloudFormation usually infers dependencies from references. Use `DependsOn` only when the relationship is not otherwise visible.

DeletionPolicy

Protect stateful resources

For important data stores, consider retain/snapshot behavior rather than deleting everything with a stack.

Nested / Reusable Modules

Reduce giant templates

Large organizations often split or wrap infrastructure into reusable modules instead of making every data engineer edit one monolithic YAML.

Secrets

Do not hard-code credentials

Use Secrets Manager / Parameter Store references and IAM rather than embedding passwords in templates.

🧱DM & ADS — 2 questionsONE-DAY PRIORITY›01
Why do you need a DM layer instead of letting ADS join DWD directly?MUST KNOW

The reservation-to-payment logic is shared by multiple downstream use cases. I centralize that logic in DM so the campaign and CRM ADS tables reuse the same business definition instead of duplicating joins and rules.

中文：预约到支付的逻辑是多个下游共用的，所以放在 DM 统一计算，避免不同 ADS 重复 Join 和口径不一致。
What is the difference between DM and ADS in this demo?MUST KNOW

DM is the reusable business layer. It combines reservation facts, paid-order facts and campaign dimensions. ADS is the consumption layer: one table aggregates campaign conversion metrics and the other keeps user-level reserved-not-paid targets for CRM.

中文：DM 是复用业务层；ADS 是最终消费层。一个做活动聚合，一个做 CRM 用户明细。
☁️CloudFormation — 4 questionsONE-DAY PRIORITY›02
What is CloudFormation?MUST KNOW

CloudFormation is AWS Infrastructure as Code. I declare the desired AWS resources in a template, and CloudFormation creates and manages them together as a stack.

中文：CloudFormation 是 AWS 的 IaC，用模板声明资源，并以 Stack 的方式创建和管理。
What are Parameters, Resources and Outputs?MUST KNOW

Parameters are deployment inputs, Resources are the AWS objects to create, and Outputs expose important values after deployment, such as the state-machine ARN.

中文：Parameters 是输入，Resources 是要创建的 AWS 资源，Outputs 是部署后的重要输出值。
Explain !Ref, !Sub and !GetAtt.MUST KNOW

Ref references a parameter or resource, Sub builds strings by substituting variables, and GetAtt reads a named attribute from another resource, such as an ARN.

中文：Ref 用来引用，Sub 用来字符串替换，GetAtt 用来取资源属性，例如 ARN。
Does CloudFormation execute the DM transformation?TRAP

No. CloudFormation provisions the Glue Job and the surrounding infrastructure. Glue executes the transformation, and the SQL file contains the business logic.

中文：不会。CloudFormation 只负责创建资源；Glue 真正执行 ETL，SQL 承载业务逻辑。
🔁Runtime Orchestration — 4 questionsONE-DAY PRIORITY›03
Why use EventBridge here?MUST KNOW

The downstream pipeline should start when upstream DWD and DIM are actually ready. EventBridge matches the data-ready event and starts the state machine, so the design does not rely only on a fixed clock time.

中文：下游应该在上游数据真正就绪时启动，所以用 EventBridge 做事件驱动，而不是只依赖固定时间。
Why use Step Functions instead of Lambda to orchestrate the workflow?MUST KNOW

Step Functions is designed for workflow orchestration. It makes sequence, parallel branches, retries and failure paths explicit, while Lambda is better used for custom code.

中文：Step Functions 适合编排顺序、并行、重试和失败路径；Lambda 更适合写自定义代码。
What does glue:startJobRun.sync mean?MUST KNOW

It starts the Glue Job and waits for the run to finish before moving to the next state. This guarantees that DM is complete before the ADS jobs start.

中文：它会启动 Glue 并等待完成，确保 DM 成功之后才跑 ADS。
Why do the two ADS jobs run in parallel?MUST KNOW

Both ADS jobs depend on DM, but they do not depend on each other. Once DM succeeds, running them in parallel reduces total pipeline latency.

中文：两个 ADS 都依赖 DM，但互相不依赖，所以 DM 成功后并行可以缩短总时长。
🔐IAM & Failure Handling — 2 questionsONE-DAY PRIORITY›04
Why are there separate IAM roles for EventBridge, Step Functions and Glue?MUST KNOW

Each service has a different responsibility. Separate roles support least privilege: EventBridge starts the state machine, Step Functions starts approved Glue jobs, and Glue receives the S3 and Catalog permissions needed for ETL.

中文：不同服务职责不同，所以分开 Role：EventBridge 启动状态机，Step Functions 启动 Glue，Glue 访问 S3 和 Catalog。
What happens if the DM Glue job fails?MUST KNOW

Step Functions retries according to the retry policy. If the job still fails, Catch sends the workflow to a Fail state, so the downstream ADS jobs do not run on incomplete DM data.

中文：DM 失败会先重试；仍然失败就进入 Fail，避免 ADS 使用不完整数据。

If you only have 5 minutes before the interview

Upstream DWD and DIM publish a data-ready event. EventBridge starts Step Functions. Step Functions runs the DM Glue job synchronously, then runs two independent ADS jobs in parallel. CloudFormation provisions the Glue resources, IAM roles, EventBridge rule and state machine. S3 stores the data, and the Glue Data Catalog stores table metadata.

中文：上游 DWD/DIM 就绪 → EventBridge → Step Functions → DM Glue → 两个 ADS 并行；CloudFormation 负责创建这些 AWS 资源，S3 存数据，Glue Catalog 存元数据。
