Level 1 — Docker and Kubernetes Overview

Understand what each tool is responsible for.
  • Docker packages an application and its dependencies, while Kubernetes runs and manages the resulting containers across machines.
    Docker 负责打包应用及依赖；Kubernetes 负责在多台机器上运行和管理生成的容器。
  • Containerization gives consistent environments, eliminates the 'works on my machine' problem, speeds up deployment, and improves resource isolation for Spark and Flink jobs on shared infrastructure.
    容器化提供一致环境，减少“本地能跑、上线失败”的问题，加快部署，并改善共享基础设施上 Spark/Flink 作业的资源隔离。
  • The same image can run in development, testing and production, making deployment, scaling and rollback more predictable.
    同一个镜像可以运行在开发、测试和生产环境，使部署、扩缩容和回滚更加可控。

Level 2 — Docker Image vs Container

Memorize the difference one sentence at a time.
  • An image is a read-only, layered template, similar to a class.
    Image 是只读的分层模板，可以类比为 class。
  • A container is a running instance of an image, similar to an object, and many containers can be created from the same image.
    Container 是 image 的运行实例，可以类比为 object；同一个 image 可以启动多个 container。

Level 6 — Secret and Persistent Storage

Understand why databases need configuration and durable storage.
  • A Secret stores sensitive values such as passwords and tokens.
    Secret 保存密码和令牌等敏感信息。
  • A PersistentVolumeClaim, or PVC, requests persistent storage and is mounted by a Pod as a directory such as /var/lib/mysql.
    PersistentVolumeClaim，简称 PVC，用来申请持久化存储，并由 Pod 挂载成目录，例如 /var/lib/mysql。
  • The PVC is usually bound to a PersistentVolume backed by local, cloud or network storage, so MySQL data survives Pod restart or replacement.
    PVC 通常绑定到由本地、云或网络存储支持的 PV，因此 MySQL 数据可以在 Pod 重启或替换后继续保留。

YAML

metadata:
  name: backend

  replicas: 2

P6. Decorator Execution

Difficulty 6/10

Question: Given code similar to the following, which statements are correct?

def verbose(f): def do_f_verbosely(*args, **kwargs): print("Calling function") result = f(*args, **kwargs) print("Function finished") return result return do_f_verbosely @verbose def check_punctuation(text): return text.endswith(".")

Correct answers:

  1. @verbose is a decorator.
  2. do_f_verbosely() runs every time check_punctuation() is called.

Step 1 — Understand the decorator syntax

The following syntax:

@verbose def check_punctuation(text): return text.endswith(".")

is equivalent to:

def check_punctuation(text): return text.endswith(".") check_punctuation = verbose(check_punctuation)

Step 2 — What happens when the function is defined?

Python calls verbose(original_check_punctuation) once. The decorator returns do_f_verbosely, and the name check_punctuation is replaced with that returned wrapper.

original check_punctuation → verbose(original function) → returns do_f_verbosely → check_punctuation now refers to do_f_verbosely

Step 3 — What happens when the function is called?

check_punctuation("Hello.")

This no longer calls the original function directly. It first calls do_f_verbosely("Hello."). The wrapper prints extra information and then executes the original function through f(*args, **kwargs).

Execution order
1. Call check_punctuation("Hello.")
2. Run do_f_verbosely()
3. Print Calling function
4. Run the original check_punctuation()
5. Print Function finished
6. Return True

Important timing distinction

PartWhen it runs
verbose(f)Usually once, when Python executes the decorated function definition.
do_f_verbosely(...)Every time the decorated function is called.
f(...)Inside the wrapper, when the wrapper decides to call the original function.
Memory rule: the decorator creates or returns the wrapper once; the wrapper executes on every call.
Common trap: saying that verbose() itself runs on every call. Normally it does not. The returned wrapper runs on every call.

C1. Smallest Positive Interval

Difficulty 5/10

Question

Implement find_smallest_interval(numbers). Return the smallest positive difference between any two values in the list.

Example Input

[1, 6, 4, 8, 2]

Example Output

1

Reasoning

After sorting, the closest pair must be adjacent. Therefore, sort once and compare neighboring values.

Python 3 Solution

from typing import List

def find_smallest_interval(numbers: List[int]) -> int:
    numbers.sort()
    best = float("inf")

    for i in range(1, len(numbers)):
        diff = numbers[i] - numbers[i - 1]
        if 0 < diff < best:
            best = diff

    return int(best)

Complexity

Time: O(n log n). The scan itself is O(n).

C2. Search a Value in Four Zones

Difficulty 5/10

Question

Implement search_value(numbers, value). Return four flags:

  1. 1 if the value appears at an even index.
  2. 1 if the value appears at an odd index.
  3. 1 if the value appears in the first half.
  4. 1 if the value appears in the second half.

All occurrences must be considered.

Example Input

numbers = [5, 8, 3, 8]
value = 8

Example Output

[0, 1, 1, 1]

Reasoning

The value appears at odd indices 1 and 3. Index 1 is in the first half, and index 3 is in the second half.

Python 3 Solution

from typing import List

def search_value(numbers: List[int], value: int) -> List[int]:
    result = [0, 0, 0, 0]
    half = len(numbers) // 2

    for index, number in enumerate(numbers):
        if number != value:
            continue

        if index % 2 == 0:
            result[0] = 1
        else:
            result[1] = 1

        if index < half:
            result[2] = 1
        else:
            result[3] = 1

    return result

Complexity

Time: O(n). Extra space: O(1).

C3. Compute Blood Gene Combinations

Difficulty 7/10

Question

Given the blood types of two parents and one child, return every possible pair of parental genotypes that can produce the child’s phenotype.

Possible phenotype-to-genotype mappings:

A  → AA, AO
B  → BB, BO
AB → AB
O  → OO

A child inherits one gene from each parent. Return the parent genotype pairs sorted first by parent 1 genotype and then by parent 2 genotype. If no valid pair exists, return [["--", "--"]].

Example 1 Input

parent1 = "AB"
parent2 = "A"
child = "A"

Example 1 Output

[["AB", "AA"], ["AB", "AO"]]

Example 2 Input

parent1 = "O"
parent2 = "AB"
child = "O"

Example 2 Output

[["--", "--"]]

Reasoning

  1. Convert each parent phenotype into all possible genotypes.
  2. Enumerate every parent genotype pair.
  3. Simulate one inherited gene from each parent.
  4. Convert the child genes back into a phenotype.
  5. Keep the parent pair if at least one child gene combination matches the required phenotype.

Python 3 Solution

from typing import List

def compute_blood_genes(
    parent1: str,
    parent2: str,
    child: str
) -> List[List[str]]:

    possible = {
        "A": ["AA", "AO"],
        "B": ["BB", "BO"],
        "AB": ["AB"],
        "O": ["OO"],
    }

    def phenotype(gene1: str, gene2: str) -> str:
        genes = {gene1, gene2}

        if genes == {"A", "B"}:
            return "AB"
        if "A" in genes:
            return "A"
        if "B" in genes:
            return "B"
        return "O"

    result = []

    for genes1 in possible[parent1]:
        for genes2 in possible[parent2]:
            valid = any(
                phenotype(gene1, gene2) == child
                for gene1 in genes1
                for gene2 in genes2
            )

            if valid:
                result.append([genes1, genes2])

    result.sort(key=lambda pair: (pair[0], pair[1]))
    return result if result else [["--", "--"]]

Complexity

The state space is constant and very small, so practical runtime is constant. The important part is correct modeling rather than performance.
