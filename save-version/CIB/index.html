Likely Questions

  • How do you structure a production ETL project?
  • How do you avoid duplicate data after retry?
  • How do you process files larger than memory?

# Check status
kubectl get pods -n <namespace>

# Inspect details and events
kubectl describe pod <pod-name> -n <namespace>

# Read logs
kubectl logs <pod-name> -n <namespace>

# Read logs from the previous crashed container
kubectl logs <pod-name> -n <namespace> --previous

# Check recent events
kubectl get events -n <namespace> --sort-by=.metadata.creationTimestamp

8. Docker

DockerfileImageContainerENTRYPOINTCMD

  • Use small and trusted base images
  • Run as a non-root user
  • Use multi-stage builds where useful
  • Keep secrets outside the image
  • Use immutable image tags for releases
Likely Questions

  • CMD vs. ENTRYPOINT?

  • How do you debug a running container?

9. Apache Airflow

DAGRetryBackfillCatchupXCom
