PROJECT STORY

60-Second Explanation

I built a small LangChain customer-support copilot that combines structured output, a deterministic preprocessing chain, RAG, conversational memory, evaluation, and a tool-calling agent. Local policy files are split into chunks, converted into embeddings, and indexed with FAISS. I expose retrieval as a policy-search tool and also provide a calculation tool. The agent decides which tools to call, while MemorySaver keeps conversation state for follow-up questions.

Core Concepts Before the Final Demo

Understand these words first. Then the code in Tab 4 becomes much easier.

Normalize
Make the question cleaner.

Example: turn an informal request into one clear sentence before later processing.

Document
A loaded source file.

Example: plans.txt becomes a LangChain Document with page_content and metadata.

Chunk
A small piece of a document.

Long files are split into smaller pieces so retrieval can find a precise section instead of returning the whole file.

Embedding
Text → numbers that represent meaning.

Similar sentences produce vectors that are close to each other in vector space.

FAISS
Vector similarity search.

FAISS stores embedding vectors and quickly finds the vectors most similar to the user's question.

Retriever
The search step.

It takes a user question and returns the most relevant chunks from the vector index.

RAG
Retrieve first, answer second.

The LLM answers using external context retrieved from your policy files.

Chain
A fixed workflow.

The developer decides the order, such as Prompt → Model → Parser.

@tool
Expose a Python function to the agent.

The decorator adds tool metadata so the model can request this function by name with structured arguments.

Agent
Dynamic decision maker.

The model decides whether to call policy_search, total_cost, both, or neither.

Memory
Conversation state.

Using the same thread_id lets a follow-up like 'What about 24 months?' reuse earlier context.

1. Build the RAG Search

First build a searchable knowledge base from the local policy files.

Input
Which plan includes audit logs?
Code
# INPUT: files inside data/
# plans.txt, refund_policy.txt, cancellation_policy.txt

docs = []

for p in Path("data").glob("*.txt"):
    loaded = TextLoader(str(p), encoding="utf-8").load()

    # Keep source file name so the final answer can cite it.
for d in loaded:
        d.metadata["file_name"] = p.name

    docs.extend(loaded)

# Chunk = small piece of a document.
splitter = RecursiveCharacterTextSplitter(
    chunk_size=400,
    chunk_overlap=60
)

chunks = splitter.split_documents(docs)

# Embedding = text converted into semantic vectors.
embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small"
)

# FAISS stores those vectors for similarity search.
store = FAISS.from_documents(
    chunks,
    embeddings
)

# A real retrieval call:
question = "Which plan includes audit logs?"

retrieved = store.similarity_search(
    question,
    k=3
)

for d in retrieved:
    print(d.metadata["file_name"])
    print(d.page_content)
Output
plans.txt
Business plan costs $99/month.
It includes audit logs and API access.

2. Turn Functions into Agent Tools

Now expose two Python functions to the Agent. `@tool` is important: without it, these are just normal Python functions.

Input
policy_search: Business plan price and features
total_cost: 99, 12
Code
@tool
def policy_search(query: str) -> str:
    """Search plan and policy documents."""
# INPUT example:
# §§PROT1§§

    retrieved = store.similarity_search(
        query,
        k=3
    )

    # OUTPUT: relevant policy text + source file
return "\n\n".join(
        f"SOURCE: {d.metadata['file_name']}\n"
        f"{d.page_content}"
for d in retrieved
    )


@tool
def total_cost(
    monthly_price: float,
    months: int
) -> float:
    """Calculate total subscription cost."""
# INPUT example: 99, 12
# OUTPUT: 1188
return monthly_price * months


# Direct test before creating the agent:
print(
    policy_search.invoke({
        "query": "Business plan price and features"
    })
)

print(
    total_cost.invoke({
        "monthly_price": 99,
        "months": 12
    })
)
Output
plans.txt → $99/month, audit logs, API access

3. Create the Agent and Memory

The Agent gets access to the tools. MemorySaver stores the conversation state for the same `thread_id`.

Input
2 tools + thread_id=customer-001
Code
model = init_chat_model(
    "openai:gpt-4.1-mini",
    temperature=0
)

# Memory = keep conversation state.
memory = MemorySaver()

agent = create_agent(
    model=model,

    # The agent may choose either tool.
    tools=[
        policy_search,
        total_cost
    ],

    system_prompt=(
        "Use policy_search for plan and policy facts. "
"Use total_cost for calculations. "
"Do not invent policy facts."
    ),

    checkpointer=memory
)

# Same thread_id = same conversation.
config = {
    "configurable": {
        "thread_id": "customer-001"
    }
}

print("Agent ready")
Output
Agent ready

4. main() — Run the Complete Question

This is the real entry point. Now you can clearly see the input, agent call, and final output.

Input
What does the Business plan include and what is the cost for 12 months?
Code
def main():
    # INPUT from the user
    question = (
        "What does the Business plan include "
"and what is the cost for 12 months?"
    )

    # Agent decides:
# 1. Call policy_search for plan facts.
# 2. Read monthly price = 99.
# 3. Call total_cost(99, 12).
# 4. Generate the final answer.
    result = agent.invoke(
        {
            "messages": [
                {
                    "role": "user",
                    "content": question
                }
            ]
        },
        config=config
    )

    answer = result["messages"][-1].content

    # OUTPUT to the user
print(answer)


if __name__ == "__main__":
    main()
Output
The Business plan includes audit logs and API access.
It costs $99/month.
12 months = $1,188.
Source: plans.txt
